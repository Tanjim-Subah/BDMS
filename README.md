## BDMS
Blood Donor Management System

---

# Fundamental Features
 ## Admin
* Comprehensive admin dashboard for management
* View information on donors
* Track available blood units and types
* Manage announcements and campaigns
* Add and manage blood collection details
* Add, edit, and delete donor information

 ## Donor
* Submit forms to donate blood
* View available blood types and units
* Access announcements and campaigns
* Enlist next donations

## General
* OTP verification for secure user registration using
* PHPMailer with Google SMTP
* Notifying if the available blood unit is less than 2
